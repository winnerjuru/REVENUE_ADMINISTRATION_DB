# Revenue Administration Database

## DBMS Assignment

This repository contains my Database Management Systems (DBMS) assignment for the **Revenue Administration Database** implemented using **PostgreSQL (psql)**.

---

## Project Overview

The project models a Revenue Administration System that manages taxpayers, tax registrations, tax declarations, assessments, payments, audits, refunds, objections, enforcement cases, and revenue targets.

The database was designed following relational database principles and includes primary keys, foreign keys, constraints, and relationships between entities.
